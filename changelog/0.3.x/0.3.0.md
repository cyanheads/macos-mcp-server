# 0.3.0 — 2026-10-21

## Changed

- **Calls that 0.2.1 answered now fail:**
  - `macos_take_screenshot` with a `path` that already exists (without the new `overwrite: true`) or that does not end in `.png`.
  - `macos_manage_displays` against displayplacer 1.2.0, whose listing has no `Enabled` line (`displayplacer_output_unrecognized`).
  - `apply_layout` while `MACOS_DISPLAY_LAYOUTS` holds an entry that is not a non-empty string (`layouts_invalid` for every layout).
  - `macos_manage_windows focus` on an app that is not running (`not_running`; it used to launch the app).
- **Retyped output fields** are now nullable, `null` when the value cannot be read:
  - `macos_get_info` and `macos://system/info`: `wifi`, `macos_version`, `display_count`. A new `unavailable` array names each failed field. (#13)
  - `macos_check_permissions`: `accessibility`, `screen_recording`, `automation_finder`, `notifications` are `boolean | null`, read from Apple's prompt-free checks. A new `unknown_reasons` says why each `null` is unknown; `notifications` is always `null`. (#22)
  - `macos_control_volume`: `level`, `muted`. A new `output_device` names an output with no software volume control, where `set` fails with `volume_unsupported`. (#26)
  - `macos_manage_windows`: `display_index`, `minimized`, plus a new `fullscreen`; `close` returns no `window`. (#30, #32, #18)
- **`macos_take_screenshot`**: the returned `path` is the resolved real path, and an existing entry fails with `path_exists`. `include_data` also sends the preview as an `image/jpeg` block first in `content[]`, only ever shrunk to a longer side of 1024 px. (#27, #19)
- **`macos_manage_displays` / `macos://displays`**: each display gains `index`, its position in `NSScreen.screens` and the `display_index` the screenshot and windows tools use. `list` returns `layouts`. A display block missing a listing line fails as `displayplacer_output_unrecognized`. (#12, #33)
- **`app_name`** in `macos_manage_windows` and `macos_take_screenshot target=window` resolves through NSWorkspace (application, localized, or process name, ignoring case). `macos_manage_windows` returns the new `not_running`. (#28)
- **`macos_manage_focus set`** echoes `enabled`. `focus_not_found` is removed; failures are `shortcuts_unavailable`, the new `shortcut_failed`, or `Timeout`. (#17)
- **`macos_send_notification`** describes that an active Focus silences the notification unless it allows the posting app.
- **Binaries**: `displayplacer` and `SwitchAudioSource` are found on PATH, `/opt/homebrew/bin`, or `/usr/local/bin` on every call (#20); macOS system binaries run by absolute path (#34).
- **`content[]` text** from upstream or caller strings is escaped so a CommonMark parse reads back the `structuredContent` value, and `macos_get_info` always prints its `Unavailable` line.
- **Names in error messages** appear as JSON string literals.

## Fixed

- **`macos_get_info`**: Wi-Fi association comes from the Wi-Fi device's link state rather than `en0`, and an SSID withheld without Location Services reads `connected: true, ssid: null` (#10). `charging` follows pmset's state token (#25). Probes work under a PATH without `/usr/sbin` (#34).
- **`macos_manage_focus set`** writes `{mode, enabled}` to the shortcut's stdin and closes it instead of blocking until the timeout (#17). A Focus state file in an unexpected shape reads as `status: "unknown"`.
- **`macos_manage_windows`**: `fullscreen` writes `AXFullScreen` instead of sending ⌃⌘F, failing as `fullscreen_unsupported` (#18). `focus` finds the window before changing anything (#21). `minimize false` restores the window, and `minimize_unsupported` replaces false successes (#30). The read-back reports the window it changed, and an osascript timeout no longer reads as `window_not_found` (#32). `list` fails `accessibility_required` instead of returning `[]` (#35).
- **`macos_manage_apps`, `macos_manage_finder trash`, `macos_send_notification`**: control characters in AppleScript literals compile and round-trip; U+0000 and unpaired surrogates fail as `-32602 invalid_arguments` naming the argument. A compile failure is never reported as `trash_refused` (#23).
- **`macos_take_screenshot`**: width and height come from the PNG/JPEG headers, never `0×0`. A failed window-id lookup keeps its own error, a Screen Recording check that cannot tell no longer counts as a grant, and each call runs under one 55 s deadline (#31).
- **`macos_manage_displays`**: a killed or failed `displayplacer` run fails the call instead of returning partial output (#33).
- **Concurrent reads**: `macos_manage_windows` list, `window_title` lookups, and `macos_manage_apps` list no longer fail with `-1719` or `-10000`, or omit an app, while a displays list or `macos://displays` read runs. NSScreen reads and System Events process enumerations never overlap within the server.
- **Same-name targets**: two processes with one name, and two windows with one title, are each listed. `macos_manage_apps frontmost` reports System Events churn as an osascript failure, not `no_frontmost_app`.
- **Script output in an unexpected shape** (empty output included) from the Finder selection and running-application scripts fails as `InternalError` instead of reading as an empty result.
- **`macos_control_audio`** skips a `SwitchAudioSource` line that is not a named input or output device.
- **Cancellation** settles as cancelled in every tool; it was sometimes reported as the mapped error (`finder_not_open`, `trash_refused`, `no_frontmost_app`) or as `null`.

## Security

- **`macos_take_screenshot` `path`**: the resolved directory must sit inside `MACOS_SCREENSHOT_DIR`, `/tmp`, or the home directory, each resolved the same way. Nothing is replaced unless `overwrite: true`, and then only the regular `.png` file the call checked; the capture never writes through a link. (#27)
