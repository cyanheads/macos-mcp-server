# 0.2.1 — 2026-10-08

## Changed

- **Framework `@cyanheads/mcp-ts-core` `^0.13.6` → `^0.13.14`.** `tools/list`, resource lists, and every input/output schema are byte-identical to 0.2.0. What callers see:
  - Tool error results carry `data.requestId`, and their text closes with `request <id>` (mcp-ts-core 0.13.10).
  - A number or boolean sent as a string (`"50"`, `"true"`) is repaired before validation, and `null` sent for an optional argument is treated as absent (0.13.14).
  - `ctx.log` notifications sent to the client honor `MCP_LOG_LEVEL` and mask sensitive fields (0.13.11).
- **Recovery hints** reach callers through the framework (0.13.10), so tool throw sites no longer forward `ctx.recoveryFor(...)` by hand in `macos_manage_apps`, `macos_manage_displays`, `macos_manage_finder`, `macos_manage_focus`, and `macos_manage_windows`. The hints callers receive are unchanged.
- **`macos_control_system` `lock`** throws its fallback-failed error through `forbidden()`; the `-32005` code and message are unchanged.
- **`server.json`** npm entries use `runtimeHint: "npx"` with no `run start:*` package arguments, and the `streamable-http` entry sets `MCP_TRANSPORT_TYPE=http` so the registry launch starts the HTTP transport.
- **Packaging**: `.mcpbignore` excludes `.cache/`, `coverage/`, `tests/`, `docs/idea.md`, and `logs/` from the `.mcpb` bundle; `package.json` `files` excludes `dist/*.mcpb` from the npm tarball.
- **`package.json`**: `rebuild` runs `scripts/clean.ts` then `scripts/build.ts` directly, `test` is `vitest run`, and `packageManager` is `bun@1.4.2`.
- **`.gitignore`** ignores every `.env*` file except `.env.example`, `.env.template`, and `.env.sample`.
- **`.env.example`** documents the current framework variables, including `MCP_HTTP_MAX_BODY_BYTES`, the `MCP_HTTP_RESUMABILITY*` set, `MCP_LOG_RATE_LIMIT_*`, `LOG_TOOL_FAILURE_PAYLOADS`, and per-signal `OTEL_EXPORTER_OTLP_*_ENDPOINT` overrides; `MCP_HTTP_HOST` defaults to `127.0.0.1`.
- **CodeQL workflow** runs `actions` and `javascript-typescript` as separate matrix jobs, each uploading under `/language:<language>`.
- **Maintenance sync**: `scripts/` (including new `install-otel.ts` and `prune-musl-packages.ts`) and `framework-skills/` resynced from mcp-ts-core 0.13.14; `CLAUDE.md` / `AGENTS.md` updated to match and the README MCP SDK badge reads `^2.2.0`.
